## 梗概（供衔接）
### 第1章 · 今日匹配（已按反馈重写：补足互动+趣事）
- 立人设：陆时被裁第三周、单身三年、人生卡壳（"天花板水渍"=停滞私密意象，无人知道）。
- App「一面」凭空出现（黑底半脸/弯月图标；开屏语"你已经一个人很久了"）。零点推 D1 **乔棠**：高冷危险、毒舌主动；批注"她不会等你…迟到的人没有第二次"。
- **趣事主线=乔棠带陆时"做三件一个人不敢做的事"**：①夜爬写字楼天台看城市；②对着全城吼最丢人的真心话（乔棠先吼"我这辈子没一天为别人活"，陆时吼"我上周被裁了我很怕"——情绪破冰）；③被保安发现，俩人逃跑大笑。全程靠拌嘴+一起闯祸堆化学反应。
- 撩拨慢升级：抽工牌、脚尖蹭脚踝、耳语；亲密升级后**淡出留白**（守尺度）。
- 暗线：乔棠直呼其名、连吼真心话都像"认识他"、最后点破"天花板水渍"（只有陆时知道）→ **App懂他到诡异(F2)**。
- 次日机制：乔棠 App 里"查无此人"，仿佛从未存在=**"一天一个、过期即逝"(F-机制)**。
- **暗线钉**：新匹配 D2 林知夏推送，批注末"陆时，昨晚那句真心话喊出来，是不是没那么可怕？"→ App 在**看着他**、且在"引导"他成长。陆时第一次的感觉是恐惧。
- 衔接第2章：D2 林知夏（社恐插画师，会脸红、慢热、反差是私下大胆），陆时开始想查 App 是什么。

### 第2章 · 她画的那张脸（首次"一鱼两吃"：甜 + 第一块拼图）
- **表层甜撩趣事**：城南文创园偶遇社恐插画师林知夏（画画时判若两人、稳又有侵略性的"看"）。趣事=夏天暴雨被困半米屋檐下，分喝一杯热水、陆时脱外套护她画具、她从躲闪到主动挪近贴肩画他。撩法走"安静、近距离、反差"路线（区别于乔棠的张扬）。亲密处**淡出留白**（"留给那场夏天的雨"）。
- **里层拼图（F5 已埋）**：林知夏讲三年前怪单——一个发抖、不停看门口的女人，无照片、凭口述细描一张男人脸两小时，付十倍价说三天后来取，**再没出现**，画留在她工作室抽屉三年。=许念（被害人）想留下凶手裴谦样貌的证据；客户再没出现=她随后被害。陆时后颈发凉但未懂。
- **暗线推进（F2/F3）**：白天破例收到 App 消息"她抽屉里那张画…那张脸你迟早会想再看一眼"——证实 App/温晚是**特意为这张画把陆时引向林知夏**。
- **陆时觉醒第一步**：意识到"林知夏不是偶然出现的，我遇见的每一个人，可能都不是"。从被动享艳遇→开始怀疑这是一盘棋。
- 衔接第3章：①陆时会惦记那张画；②今日新匹配 D3；③季野登场查 App。

### 第3章 · 河边的鼓点（D3 白朗 / 季野登场 / 第二块拼图）
- **季野登场**：大学室友、开小酒馆。帮查「一面」=查无来源/公司/备案/服务器，"干净到不正常""像专门冲你一个人下的套"，劝陆时卸载。陆时没卸——他开始想知道"套的尽头是什么"。（季野=吐槽+外部视角+悬疑放大器。）
- **D3 白朗**：独立乐队鼓手，齐耳短发、咋呼像团电，打鼓时判若两人（手腕翻飞、点燃全场）。批注"这一个吵，但你今天正需要点动静"。
- **表层趣事**：livehouse 跳闸停演→白朗一怒把演出搬到江边打不插电，陆时被抓壮丁搬鼓、当VIP观众；原始鼓点点燃江边。撩法走"汗、肾上腺素、节拍"路线（她绕到身后握他手敲鼓、下巴搁肩、耳语"节拍骗不了人，你心里多闷手底下多重"）。亲密淡出（"留给那条江"）。
- **里层拼图（呼应F5，推进F4）**：白朗三年前接过对岸冷白玻璃大楼那家公司的年会，记得唯一对乐队好的设计师姐姐**许念**——那晚许念状态极差：**躲角落、不停回头看门口、打完一个电话手抖到端不稳啤酒**；不久辞职"人间蒸发"。陆时把它与ch2林知夏的怪客户（发抖、看门口、画完脸消失）对上=**同一个人许念，同一种恐惧**。两块碎片首次拼合。**地理钉子**：对岸那栋"冷白色高楼"=裴谦公司（疑与抛尸案/江边相关）。
- **暗线（F2/F3）**：App 结尾"她记得的那栋楼你也记一记""慢慢来，陆时，我不急"——温晚有的是时间、在一步步往一个陆时看不见的地方带他。压迫感升级。
- 衔接第4章：①拿画；②D4图书管理员；③季野线。

### 第4章 · 闭馆之后（拿到画/实物拼图 + D4简宁 + 案子推进 + 疑似知情者）
- **机制澄清+主题（重要）**：陆时回头找林知夏（违抗"过期即逝"），**林知夏记得他**=女孩们是真实的、不会被忘记，"一次性"是 App 制造的假象。陆时偏要"回头"。→ 确立grounded（女孩真人、关系可延续）+ 主题（拒绝把人当一次性）。
- **实物拼图入手（F5兑现）**：林知夏交出三年前那张画——**男人脸：四十多岁、西装昂贵、头发一丝不苟、眼神冷得像看货物**（=凶手裴谦，陆时尚不知其名，但确信"以后一定会再见到"）。陆时翻拍存证。林知夏一句"你查这个会有危险吗"=危险预兆。
- **D4 简宁**：老图书馆管理员，安静、声音轻、克制下暗涌（"安静的人心里的浪最大"）。趣事=闭馆后留下帮归架旧期刊，寂静书库里被迫压嗓的近距离低语=张力。亲密淡出（"留给闭馆之后的图书馆"）。
- **案子推进（F4）**：陆时借图书馆查三年前报纸，找到官方说法——"许某辞职后**移居海外**、与家人失联、警方**排除刑事嫌疑不予立案**"。与白朗/林知夏所见（恐惧、蒸发、留下仇人脸）全相悖→**官方在掩盖**。
- **简宁=疑似知情者（新悬念）**：她翻报纸**精准到那一页**，坦言"这条新闻我也找过很多遍"，意味深长。→ 她可能是温晚安排的知情同谋 / 或另有立场。埋钩。
- **暗线（F2/F3）**：App 收尾把问题递进——"许念没有移居海外，那她去哪了？"温晚用一个个滚烫夜晚把陆时一步步骗进命案。**陆时心态转折**：开始"想往里走了"（主动入局）。
- 衔接第5章：①追问许念去向→抛尸地；②D5健身教练；③危险逼近。

### 第5章 · 她想学会打人（D5 柯蔓 / 锁定疑似抛尸地 / 危险首次贴身）
- **D5 柯蔓**：拳击教练，直球、不绕弯、肢体感强、阳光带攻击性（区别于乔棠的危险冷）。趣事=深夜空拳馆教打拳：扳胯纠正姿势、举靶、"碰到我一拳就听你的"的赌约、拽进怀里。肢体张力拉满（呼应用户要的"运动接触"撩法）；亲密淡出（"留给深夜的拳馆"）。台词"闷骚型憋得狠打起来反而狠""我喜欢"=直球人设。
- **里层拼图（F4大推进，锁定地点）**：
  - 江边一片**烂尾工地**：三年前突然停工封死至今，属**裴氏**（=江对面冷白楼，ch3已钉）。本要建总部园区，地基打一半喊停。**强烈指向抛尸地**。
  - 柯蔓记得三年前会员许念：突然拼命学防身/挣脱/打要害，自言"我怕有一天得靠这个保命"；失踪前最后一句"**柯教练，要是哪天我不见了，你别信他们说的**"。→ 许念预知自己有难，反复印证（ch2画脸/ch3看门口/ch4官方掩盖）。
- **危险首次贴身（卷二引擎）**：上周有黑衣男在工地围挡外打听"是不是有个不相干的人老打听这片地"=**裴谦一方已注意到陆时的调查**。柯蔓警告"那片地别一个人去"。
- **暗线（F2/F3 大推进）**：App收尾——"那片地就是你想的那样""他们盯上你了，这局我护着你，一步步来""**别急着送命，我等了三年不差这几天**"。→ 温晚为此局准备了三年、知道工地埋着什么、知道盯梢者是谁、知道许念去向、且要保护陆时。
- **陆时心态再转**：不再怕 App，**开始想见 App 背后的人**（"她是谁"成为新驱动）。为卷二"查 App 来历 / 逼近温晚"铺路。
- 衔接第6章：卷一收尾，悬疑推向温晚 + 危险升级。

### 第6章 · 我早就认识她（卷一完 / 直指温晚 + 危险贴脸 + 温晚远程救他）
- **危险升级**：黑衣人进季野酒馆打听陆时（"你那姓陆的朋友最近忙啥"）。季野定性"这是有人要弄死你"。陆时却已决定主动入局、要问出 App 背后的人。
- **D6 辛夷**（塔罗占卜师，神秘魅惑、明显知情）：受"她"之托陪陆时一晚，可问，但"答几分看牌"。氛围撩（烛光/檀香/眼尾痣/凉指尖）但本章重心转向悬疑（卷一→卷二的基调切换），无fade，被危险打断。
- **第一条直指温晚的明牌（但不点名，慢炖）**：辛夷借塔罗（倒置恋人/高塔/星星）说——做 App 的是个**女人**；"三年前一座塔塌了，砸碎两个人：一个被迫躲进黑暗，一个以为自己只是被抛下"；"你早就认识她，很熟，熟到知道你天花板那块水渍是哪年漏的"；"她躲三年不是不想见你是不敢，她欠你一个解释，这整个局都是为把解释亲手交给你"。转交一句"看着你三年对着水渍发呆，她也很难受"。→ 强暗示温晚，但**名字留给温晚亲口说**（辛夷明言：现在说出来你会冲动坏了局、把自己搭进去）。
- **温晚远程救命（坐实她的能力与守护）**：陆时归途被黑衣人堵死巷（"有位老板想请你聊聊，你打听太多了"）。App 远程**掐灭整条街路灯、引爆全街防盗警报、指引未锁后门**助其逃脱。收尾"对不起把你卷进来…再等等我，快了"。→ 证明她有顶级技术/资源、在实时看护、为此局备战三年。
- **卷一终钩**：陆时再也按不住那个名字——"**温晚。会是你吗。**"（读者已确信，陆时半信半疑、不敢信。慢炖到卷二/卷三正式相认。）
- **F2/F3/F4 全部推进**；危险线（裴谦方→"那位老板"）正式成为追杀线。
- 衔接第7章（卷二开篇）：重审温晚旧事 + 给温晚血肉 + 推进相认倒计时。

### 第7章 · 她不是离开（卷二开篇 / 温晚血肉与"她在逃命"的click / 裴谦得名）
- **温晚闪回（给暗线人物血肉）**：两年恋情；她聪明明亮、嫌他慢、半夜煮面；天花板水渍是两人一起接的盆（她还养过金鱼"反正漏了不如风雅"）。三年前陆时被裁垮掉、自我封闭，温晚留字条"对不起我得走了别找我"消失，陆时一直以为是自己把她耗走、不配去找。
- **重审=她在逃命的click（F3大推进）**：温晚走前两月反常——半夜对电脑、听动静即关屏、换三次手机、问"我突然消失你信别人还是信自己"、不停回头看门口、手抖=**和许念一模一样的害怕**。陆时查温晚→三年前起"查无此人"（社保停/账号注销/痕迹全无），**与许念同公司、同年、同时消失**。结论：温晚不是离开他，是和许念撞见同一件事、她跑掉了；让他恨她别找她，是为保他安全。
- 陆时直问 App"是你吗温晚"，温晚（经App）首度近乎承认："还不行，我现在出来咱俩都得死，再帮我走完最后几步，到时我自己站到你面前。"→ 相认正式进入倒计时。
- **D7 应清**（高冷策展人，智性撩，雨天画廊）：撩在脑子上、不动声色。趣事偏静、偏机锋。台词"来约会还想着别的女人，很失礼""有些人不是你随时回头都还在原地的"=既撩又点题。
- **裴谦得名（F4大推进）**：画廊"年度赞助人"合影里，陆时认出**林知夏画中那张冷脸=裴谦，裴氏科技老板、艺术圈"大善人"、常年捐钱办展**。凶手有了名字+体面外壳（有钱有势被赞为善人）。应清淡淡补刀"三年前他们公司有个女孩笑着笑着'出国'了再没回来"=又一块拼图，温晚的网密。
- **陆时情感转向（卷二主题）**：他不想再见别人，只想见温晚（"我只想见你"）。算法的艳遇在"真有一个温晚"面前变得空洞——他要的是一个真实的人，不是每天一个新鲜的。
- **卷二倒计时钩**：温晚答"再见三个人，三个人之后，我带你去一个地方，那天我在那儿等你。"→ 还剩3个女孩(D8/D9/D10)，之后相认。
- **新警示**：App"别恨太早，你还没看见他做过最脏的那件事""别急着去工地，证据只有一次机会，挖早了全完"=吊更大反转(裴谦更深的罪/F-待埋) + 设定取证唯一性（防止过早高潮）。
- 衔接第8章：D8舞者，给温晚三年血肉 + 危险烧到季野，倒计时3→2。

### 第8章 · 贴着跳的舞（D8 桑雅 / 温晚三年揭露 / 危险殃及季野与女孩们）
- **D8 桑雅**：探戈舞者，泼辣护短，温晚的旧友（App首次把女孩直接与"她"相连）。趣事=米隆加舞厅教探戈，贴身双人舞张力（"别用脑子，我往哪带你往哪走"——呼应陆时近况的黑色幽默）。本章无fade（重心给情感）。
- **温晚三年血肉（F3大推进，给暗线注入痛感）**：桑雅当年把温晚藏在自家地下室小半年——温晚雨夜来投、攥U盘、"有人要杀我，不能就医/报警/联系任何人，尤其不能联系陆时"。她躲着不敢开灯，**偷连陆时楼下便利店摄像头**，隔着画面看陆时三年（看他几点下楼、是否变瘦、蹲门口）；看见他蹲便利店那次哭了一整夜"是我把他害成这样，可我一去他就死"。→ 解释"水渍/发霉的日子有人看着疼着"，温晚的牺牲与爱具象化。
- 桑雅替温晚立威/给陆时压愧疚："这最后几步你敢退缩敢让她三年白熬，我亲手弄死你。"
