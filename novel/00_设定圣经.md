# 《回声邮局》· 设定圣经（Worldbuilding Bible）

> 这是全书设定的唯一权威来源。每写一章都对照此文件，任何新增设定先回填到这里，避免长篇写崩。

---

## 一、核心设定：残响

- 人脑在临床死亡后，会残留一段微弱的神经电活动——官方术语称**「残响」（Echo）**。
- 残响不是灵魂、不是记忆全集，而是逝者**死亡瞬间最强烈的那个念头/未说出口的话**，像一段正在缓慢消磁的录音。
- 自然状态下，残响在死后**约 72 小时**内彻底消散。
- 残响**不可逆、不可复制**——一旦捕捉读取，原残响即被「取出」，逝者再无残响。
- 残响有强弱：牵挂越深、遗憾越重，残响越强、越完整；安详离世者几乎无残响。

## 二、残响邮局

- 全称**国家残响管理局·投递处**，民间简称**残响邮局**。半官方机构，体制内但讳莫如深。
- 职能：用专用设备（**残响采集舱**）在死者死后 72 小时内捕捉残响，整理成一封**「回声信」**，投递给残响所指向的牵挂之人（收信人）。
- 一封回声信 = 一段被转译为文字/影像的残响。普通家属只知道这是「逝者最后的心意」，不知技术细节。

### 投递铁律（全局唯一的硬规矩，结局会被打破）
1. **投递员不得拆信**——回声信由收信人亲启。
2. **投递员不得回应残响**——残响是单向的，回应会造成不可控后果（卷三揭示真相）。
3. 一名收信人一生只会收到一封回声信。

## 三、技术名词

| 名词 | 含义 |
|---|---|
| 残响（Echo） | 死后残留的最后念头 |
| 回声信 | 残响转译成的可投递信件 |
| 残响采集舱 | 捕捉残响的设备，需在 72h 内使用 |
| 共感（Resonance） | 极少数投递员能直接「听到」残响的能力（沈默有） |
| 沾染（Residue） | 共感者投递后短暂沾上逝者情绪的副作用 |
| 养响 / 延存（第5章实证登场） | 用采集舱**持续维持**一缕残响、不让其在72h内消散的违规技术。表征：采集舱指示灯由"瞬时即熄"变为**长亮**；舱内残响呈疲惫、循环往复状（像被困者重复同一句话）。挂三级密级。官方/项目内称「长明维持」。 |
| 长明计划（第8章） | 养响的官方项目名，负责人=副局长**顾延**。对外包装成付费服务「永驻」（富人花钱让逝者残响被长明维持、可预约隔舱"感受"亲人）。**但名单中约1/3残响家属不知情**，对应舱被反复"采集"——见下「井」。 |
| 「井」（关键机理，第8章） | 残响一经采集即消散（铁律，仅能采一次）；但被长明维持的残响**不消散**，于是可被**反复采集无数次**。一个人临终最后一念被困住、永远说不完、被一遍遍榨取。林岸喻为"一口永远打不干的井"。**打井取的"水"是什么=卷三最终真相（录像里被切掉的"拿这些念头去——"）。** |

## 四、世界基调

- 时间：近未来，约当下 + 20 年。城市潮湿、多雨、霓虹与老旧楼宇并存（赛博 + 旧物的混搭质感）。
- 科技不炫目，残响技术是唯一的「奇点」，其余生活与今日相近。
- 整体氛围：克制、潮湿、温情中藏着寒意。
