# 《一期一会》· 设定圣经

> 全书设定唯一权威来源。每章对照，新增设定回填此处。

## 一句话
三十岁那年的一个转变，让江照开始相信"每个擦肩而过的人，都是一本没翻开的书"。他在城市的各种场合，真心地搭讪、认识一个个陌生的女孩——用真正的高情商（看见、倾听、共情、尊重），在三两天的相处里走到心动与亲密，又好聚好散，奔赴下一段相遇。一部"既当故事看、又能学到怎么真诚待人"的都市恋爱群像。

## 视角 / 文风
- **第一人称「我」（江照）**，温暖、敏锐、带点松弛的自嘲。都市质地、对白多、画面感强。

## ⭐ 写法铁律（每章必守）
1. **每章开场=一次真实的搭讪**，场合章章不同。搭讪过程写细、写出门道（见下）。
2. **节奏：一个女生≈三天小弧光**——搭讪相识→约会升温→谈恋爱/接吻/亲密→好聚好散→下一个。每个女生≈1章（6–9千字），出彩的拆2章。
3. **互动与趣事是重头**：靠"一起做一件事"产生化学反应，别干坐着聊。
4. **结局有变化、不搞猎艳记分**：真心却错时光好好告别 / 只是合适的过客 / 留念想 / 偶有舍不得换的（埋结尾伏笔）。江照始终真诚在场、坦诚不欺骗。

## ⭐ 高情商搭讪三要点（每章自然演示，也是"反操控"的体现）
1. **开场不用套路台词**：从当下情境/对方正在做的事里，找一个真诚的切入点。
2. **读对方的舒适度**：肢体、眼神、回应热度，随时校准；不施压、不纠缠。
3. **没兴趣就体面退场**：可写"被礼貌拒绝"的段落，更真实、更显教养，也教读者"被拒时怎么得体"。

## ⚠️ 内容尺度（硬约束）
- **可写**：暧昧、心动、性张力、调情；牵手、拥抱、**接吻（可较细腻：气息、试探、温度、节奏）**、贴近、耳语。
- **前戏/缠绵的氛围可写得大胆、成人、有热度**：接吻深浅、轻哼/喘息、薄汗与体温、攥紧的手、散落的头发、"上楼/进门/褪去防备"——这些铺陈到位，让"发生了"明明白白。
- **不写**：性器官特写、性行为过程本身的露骨描写（动作 play-by-play）。镜头停在"门后/灯灭"那一步，**淡出/留白**。
- 一句话定位：**前戏与欲望的张力写足；做爱过程不写。**
- **始终**：双方自愿、相互、平等；女生是有主体性的完整的人，不是战利品；不写操控/算计框架。
- 接吻是基线，更进一步则淡出；且不是每段必有。

## "情商可学"层（每章演示一条，登记于03避免重复）
真好奇 / 听潜台词 / 自信≠自大 / 真诚看见≠奉承 / 尊重"不" / 坦诚与示弱 / 幽默分寸 / 全然在场 / 不带目的的给予 / 接住情绪。

## 主角 · 江照
30岁，自由插画/设计师，时间灵活。职业只是背景，**绝不当搭讪借口**。搭讪出于真实转变（三十岁那年的契机：暂定父亲突然离世）。温暖敏锐、不带目的的好奇、自信不自大、会幽默会示弱、尊重边界。轻量暗线：从"认识很多人却没真正留住谁"到慢慢懂"连接"。

## 一致性检查清单（每章自检）
- [ ] 开场是否一次真实搭讪？场合是否与前面不同？
- [ ] 尺度守住（撩/吻到位，露骨淡出）？
- [ ] 情商是"真诚连接"非"操控"？女生有主体性、非工具人？
- [ ] 本章女生性格/星座/MBTI/职业/年龄与已出场者有区分度（查03）？
- [ ] 本章情商原则真实健康、且不与前章重复？
