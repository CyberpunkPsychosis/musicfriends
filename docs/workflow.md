# AI 协作音乐制作工作流（EDM）

> 一句话定位：**你是创意总监，AI 是不知疲倦的编曲乐手 + 音色设计师 + 混音助理。**
> 你出想象力和审美判断，AI 包掉重复的技术劳动；任何环节你都能随时接管。

---

## 0. 角色分工（最重要）

| 环节 | 谁主导 | 说明 |
|---|---|---|
| **旋律 / 主题** | **你** | AI 先出一版当"引子"给你灵感，但方向你定、你改 |
| **音色 / 声音设计** | **AI 重点帮**（你的痛点）| 见 §4 —— MIDI 不带音色，靠参考音频 + 预设推荐 + 真实 VST 处理 |
| **节奏 / groove** | **AI 重点帮**（你的痛点）| AI 出鼓组与 groove 的多个变体让你挑 |
| **整首结构 / 编曲** | AI 先搭，你调 | AI 出"整首 v1 脚手架"，你在上面增删 |
| **FL 里的精修** | **你** | 钢琴卷帘、自动化、音色微调都在你手里 |
| **第一遍混音** | AI 先混 | 在导出的 stems 上做 EQ/压缩/响度，给你起点 |
| **终混 / 母带审美** | **你**（AI 辅助）| 你的耳朵说了算 |

**原则：你始终握方向盘，AI 把脏活累活做完。**

---

## 1. 黄金法则：一切模块化

不要"成品大文件"，要"一堆可单独替换的积木"。这是"足够灵活"的唯一前提。

- **纵向拆轨**：鼓 / bass / 和弦 / 主旋律 / pad / FX，每条单独
- **横向拆段**：intro / verse / **buildup** / drop / break / outro，每段单独
- 任何时候你说"buildup 再炸一点"，AI **只重写那一块**，其它一个音不动

---

## 2. 交接媒介（AI ↔ FL 怎么传东西）

我们是**"文件交接"模式**，不是"远程遥控 FL"模式（原因见 §5）。三种媒介：

| 媒介 | 用途 | 谁原生支持 |
|---|---|---|
| **MIDI（`.mid`）** | 创作骨架：和弦/旋律/鼓/bass，可在 FL 任意编辑 | FL 直接拖入 |
| **参考音频（`.wav/.mp3`）** | 定音色方向、定整首 vibe，给你听个"目标长什么样" | 你听，不编辑 |
| **Stems（分轨 `.wav`）** | 混音：你导出分轨 → AI 处理 → 你收尾 | FL 导出/导入 |

## 3. 一首歌的生命周期（核心循环）

```
① 你给方向    "140 BPM melodic dubstep，先压抑后释放"
      ↓
② AI 出整首 v1  多轨 MIDI（脚手架）+ 一版参考音频（定 vibe）
      ↓
③ 你找灵感     听参考、看 MIDI → 自己写/改主旋律（你的地盘）
      ↓
④ 局部来回     "drop 和弦太普通" → AI 只出 chords_drop 的 3 个变体
              "buildup 不够炸"  → AI 只重写 *_buildup 那几轨
              （你也可以自己替换任意一块，再丢回给 AI 接着改）
      ↓
⑤ 音色 & 节奏  见 §4，AI 帮你定音色方向、出 groove 变体
      ↓
⑥ 你在 FL 精修  换音色、画自动化、调细节
      ↓
⑦ 导出 stems   AI 先混一版（+ 一份"我动了哪些参数"清单）
      ↓
⑧ 你收尾      在 AI 的混音基础上按自己耳朵定稿
```

每一步都能往回跳，永远在小块上迭代，不推翻全局。

## 4. 针对你两个痛点的专门打法

### 痛点 A：音色 / 声音设计

**关键认知：MIDI 只有"音符"，没有"音色"。** 音色 = 你用哪个合成器/预设/采样。
所以 AI 不能靠 MIDI 直接给你音色，而是三条腿一起上：

1. **参考音频定向** —— AI 生成/找一段目标音色的音频，你照着调，"耳朵有靶子"
2. **预设 & 工具推荐** —— "这个 supersaw 用 Serum 的 X 类预设 + unison 7 voices + 这样的滤波"，把摸索过程省掉
3. **真实 VST 处理 stems** —— 用 `pedalboard`（见 §6）在 Python 里**加载你自己的 VST 插件**处理导出的音频，所以"AI 帮做音色/混音"是真用你的插件，不是玩具音

### 痛点 B：节奏 / groove

- AI 出**鼓组 MIDI 的多个变体**（不同 hi-hat 切分、不同 kick 律动、加 swing/groove 量化）
- 你挑一个或让 AI 在你哼的节奏上扩展
- fill、buildup 的鼓点加密这种重复活，AI 包掉

## 5. 诚实说明：FL Studio 这道墙 ⚠️

- ❌ AI **不能直接操作你电脑上的 FL**（没法帮你点鼠标、调旋钮）
- ❌ FL 的工程文件 `.flp` 是**封闭私有格式**
- ✅ 但 AI 能在**进 FL 之前**和**出 FL 之后**包掉所有重活：
  - 进之前：生成 MIDI、生成参考音频、用 `pyflp` 摆好工程骨架
  - 出之后：用 `pedalboard` 在 stems 上做混音/音色处理
- 衔接媒介就是 MIDI + stems，FL 都原生支持，所以交接很顺

> 题外话：如果哪天想要"AI 直接遥控 DAW"，**Reaper** 是唯一可被脚本完全控制的主流 DAW。但你习惯 FL，我们走 MIDI/stems 这条路，完全够用。

## 6. 工具链

| 工具 | 作用 | 状态 / 要求 |
|---|---|---|
| **MIDI 生成**（自写算法 / `mido`） | 出和弦、鼓、bass、旋律骨架 | 免费、本地、零依赖 |
| **`pyflp`** | 读/部分写 `.flp`，自动摆轨道、命名、塞 MIDI | pip 装，开源 |
| **`pedalboard`**（Spotify 开源） | Python 里加载**真实 VST3** 处理音频，做 AI 第一遍混音/音色 | pip 装；需你本地有 VST |
| **音乐大模型**（Suno / Udio / MusicGen / Stable Audio） | 出"整首参考音频"定 vibe，或出带人声成品 | 需 API key / 付费；本地 MusicGen 可免费但要算力 |
| **`matchering`** | 参考曲母带匹配（响度/频谱对齐），省掉重复母带活 | pip 装，开源 |

> 当前这个云环境：能装 pip 包、能跑 Python 算法、能合成 WAV；**没有**音频合成器和你的本地 VST，所以"用真实 VST 处理"那步要在你自己机器上跑。大模型 API 也需你提供 key。

## 7. 命名与目录约定

让"按段/按轨替换、AI 互不打架"成立，靠统一命名：

```
<曲名>/
  reference/        AI 出的整首参考音频
  midi/
    drums_intro.mid    drums_buildup.mid    drums_drop.mid
    bass_drop.mid      chords_drop.mid      lead_drop.mid
    ...
  stems/            从 FL 导出的分轨
  mixed/            AI 第一遍混音输出 + 调参清单
```

规则：`<轨>_<段>.mid`。你说"重做 buildup 的鼓"，AI 就知道只动 `drums_buildup.mid`。

## 8. 下一步候选

- 跑一遍真实流程：你给个具体需求，AI 出一组 EDM MIDI 让你拖进 FL 试手感

- 接大模型：你提供某家 API key，打通"AI 出整首参考音频"
